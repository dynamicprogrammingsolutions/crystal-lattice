# Crystal Lattice Support

Choose the route that matches the request. Public GitHub issues must not contain
credentials, private conversations, personal data, private infrastructure
details, or security-sensitive information.

## Usage, Installation, And Connection Questions

For installation help, mobile connection problems, and self-hosting questions,
use the [Crystal Lattice support page](https://crystallattice.dev/support) or
email [support@dynamicprogrammingsolutions.com](mailto:support@dynamicprogrammingsolutions.com).

Include the affected Crystal Lattice version or commit, operating system or
device, connection method, steps taken, and exact error. Remove credentials,
tokens, private messages, and personal data from logs and screenshots.

## Reproducible Software Bugs

For a reproducible defect that contains no sensitive information, use the
[bug report form](https://github.com/dynamicprogrammingsolutions/crystal-lattice/issues/new?template=bug.yml).

Search existing issues first. Include the smallest reproduction you can provide
and identify the affected package, application, or service.

## Feature Requests

Use the
[feature request form](https://github.com/dynamicprogrammingsolutions/crystal-lattice/issues/new?template=feature.yml)
to describe the problem or use case, desired outcome, affected area, and
important compatibility or operational constraints.

## Security Or Sensitive Reports

Do not open a public issue for a suspected vulnerability, exposed credential,
or report that requires private data. Follow the private process in
[SECURITY.md](SECURITY.md).

## Support Boundaries

Crystal Lattice is in early development. Support is provided as capacity
allows; there is no guaranteed response time or support SLA.

The bridge and cloud-orchestrator components are self-hosted. Dynamic
Programming Solutions Kft. does not currently operate a public production
bridge or cloud-agent service.

Support for third-party AI providers, Apple or Google developer accounts,
GitHub, cloud infrastructure, and independently operated Crystal Lattice
environments remains subject to those providers' or operators' own support
policies.
