# Crystal Lattice Product Website Documentation

The `landing_page` package builds the public Crystal Lattice product website
from authored YAML, Markdown, Astro components, and approved public assets.

## Development

- [Website development](development/index.md): current content-system
  implementation, product-website content targets, and research knowledge.
- [Package README](../README.md): local build, preview, deployment, and public
  URL configuration.

The deployed website content is authored under `src/content/`. Development
research and target specifications are supporting sources and are not rendered
as public product claims automatically.
