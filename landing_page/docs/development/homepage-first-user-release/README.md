# Homepage First-User Release

Status: **Brief and terminology direction approved; copy, visual plan, and
image plan require revision — not implemented.**

Updated: 2026-10-24

This package defines the proposed first-user homepage before implementation.
It separates product language, information architecture, visual composition,
and screenshot production so that source components do not make those
decisions implicitly.

The currently implemented opt-in product-overview preview is retained as
Candidate A in commit `96e08249`. It is comparison material, not the selected
target.

## Review documents

- [Brief](brief.md) defines the page role, visitor questions, terminology,
  concept ownership, information order, claim boundaries, and acceptance
  criteria.
- [Copy draft](copy-draft.md) contains three complete opening-copy directions
  and the shared proposed overview wording. It contains visitor-facing text,
  not implementation instructions.
- [Visual plan](visual-plan.md) maps the proposed copy to intentional desktop
  and mobile compositions, section tones, text measures, figure treatments,
  frames, and responsive rules.
- [Image plan](image-plan.md) maps each proposed visual to one claim, a real
  product source, capture geometry, inline treatment, and approval state.

## Approval sequence

1. **Complete:** approve the page role, visitor questions, concept ownership,
   and terminology.
2. Select one complete opening-copy direction and correct its wording.
3. Approve or correct the visual plan independently from the copy.
4. Approve the image shortlist and capture treatments.
5. Implement only the selected direction in the normal homepage content and
   maintained visual-asset lifecycle.

The copy and visual plans may be reviewed together, but both decisions must be
explicit. Approval of this package does not promote visual sources, modify
current public content, push source, or publish the website.
