# Website report fixture

This capture-only application plugin renders `reports.json` through the real
application action API and native action-display window. It is not a built-in
product plugin and is not loaded by normal application configuration.

The fixture has three days of `claude` and `zai` costs and three days of an
illustrative ChatGPT weekly window. The screenshot assumes 100% corresponds
to about $550 over seven days: 0% → 40% therefore gives $220 estimated usage
and a change of 40 percentage points. This is not a provider billing or
subscription-price claim.

Currency formatting uses two decimal places in this fixture only. The real
cost and ChatGPT usage plugins retain their existing behavior.
