# Agent Evaluation Documentation

Use these pages according to the work you are doing:

- [Quickstart](quickstart.md): run a first Crystal Lattice evaluation, inspect
  its result, and continue it.
- [Environments and customization](environments.md): understand the generic
  environment contract, Crystal Lattice context, request drivers, stopping,
  configuration, snapshots, evaluation, and presentation.
- [Continuation and cache](continuation-and-cache.md): reuse conversation and
  repository state safely.
- [Artifacts and evidence](artifacts-and-evidence.md): select compact
  AI/human inputs while retaining raw diagnostics.
- [Development](development/index.md): package architecture, tests, and
  maintenance boundaries.

The target specification lives separately under
`maintainer/specifications/agent-evaluation-framework/`. These pages describe
current implemented behavior.
