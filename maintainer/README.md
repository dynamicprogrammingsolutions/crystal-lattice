# Maintainer

This domain contains non-public documentation, reusable maintenance tools,
specifications, evaluation suites, and evidence used to maintain Crystal
Lattice guidance and agent workflows.

Start at:

- [Maintainer documentation](docs/index.md)
- [Maintainer development and specifications](docs/development/index.md)
- [Agent evaluation](agent-evaluation/README.md)
- [Guidance source and compiler](guidance/README.md)

`maintainer/` is an audience and publication boundary, not one document type.
Cross-cutting concepts and interpreted results live under `maintainer/docs/`.
Reusable products keep documentation and specifications with their package.
Suite scenarios and frozen records remain with the suite that owns them.

Public documentation and the guidance applied by ordinary contributors remain
under root or package documentation. Public pages do not need to link back to
this maintenance domain.
