# Maintainer documentation

This documentation is for people who maintain Crystal Lattice guidance,
evaluation tooling, publication behavior, and related workflows. It is not
part of the public product documentation.

Start with:

- [Instruction delivery and authority](instruction-delivery-and-authority.md)
  for the distinction between a maintained source, its delivery channel,
  instruction priority, availability, and observed use.
- [Guidance maintenance workflow](guidance-maintenance-workflow.md) for the
  change, evaluation, approval, promotion, and adoption process.
- [Evaluation results](evaluations/index.md) for human-readable findings and
  the current accepted guidance state.
- [Maintainer development](development/index.md) for ownership, architecture,
  and specifications governing this domain.
