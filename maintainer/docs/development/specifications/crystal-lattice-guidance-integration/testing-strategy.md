# Crystal Lattice guidance integration testing strategy

Verification includes:

- root and package link and routing checks;
- documentation-site registry, assembly, navigation, and build tests;
- exact root-guidance compilation and task-guidance synchronization;
- package-specific migration checks;
- documentation-guidance behavioral scenarios using explicit instruction
  delivery provenance;
- frozen producer, semantic, and pairwise records where valid;
- human review for clarity and acceptance.

A run is incomplete when a required producer output, semantic record, or
pairwise record is missing. Direct injection is not reported as discovery, and
task-mode integration is not accepted until a real task file is produced and
assessed.
