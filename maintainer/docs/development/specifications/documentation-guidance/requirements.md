# Documentation and specification guidance requirements

These requirements define the reusable guidance product. Crystal Lattice
repository integration, publication, migration, and concrete evaluation
requirements are tracked separately.

Implementation values use `Not started`, `In progress`, `Implemented`,
`Deferred`, or `Removed`.
