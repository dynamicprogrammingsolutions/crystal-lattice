# Agent evaluation framework requirements

These requirements track the live implementation, verification,
documentation, and evidence state relative to the target specification.

Feature prefix: `AEVAL`

Implementation values use `Not started`, `In progress`, `Implemented`,
`Deferred`, or `Removed`.

| ID | Requirement | Implementation | Verification | Documentation | Evidence |
|---|---|---|---|---|---|
| AEVAL-001 | A maintainer-owned Python package exposes a generic evaluation kernel under the `agent_eval` import without making it public product documentation. | Implemented | Automated | Documented | `maintainer/agent-evaluation/`; package import tests; Checkpoint 1 |
| AEVAL-002 | `AgentEval.run(name, program, *, environment=None, continue_from=None, workspace=None, cache_key=None)` is the minimal stable kernel execution contract. | Implemented | Automated | Documented | `src/agent_eval/eval.py`; exact-signature test; README |
| AEVAL-003 | The generic kernel owns run identity, workspace, cache, parent linkage, artifacts, and error preservation without hardcoding agent prompts, messages, tool loops, snapshots, assertions, scoring, or presentation. | Implemented | Automated | Documented | Generic kernel tests; no Core/Application imports; README |
| AEVAL-004 | A single `RunEnvironment` contract provides the broad replacement seam for context creation, compatibility fingerprinting, state restoration/snapshotting, and environment-specific final observations. | Implemented | Automated | Documented | `src/agent_eval/environment.py`; replay-environment substitution and continuation tests |
| AEVAL-005 | The first `CrystalLatticeEnvironment` uses Core/Application, supports caller-owned configuration and plugins, and exposes a context with direct access to application, core, session, configuration, workspace, and run services. | Implemented | Automated | Documented | Real `AgentApplication`/`AgentCore` construction, plugin-loading, request, streaming, tool-loop, cache, continuation, and cleanup tests; package docs |
