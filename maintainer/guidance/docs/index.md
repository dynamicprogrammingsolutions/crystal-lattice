# Agent guidance compiler

The compiler assembles a shared bundle and a project-owned target into normal
guidance files such as `AGENTS.md`.

- [Quickstart](quickstart.md)
- [Development](development/index.md)
- [Compiler specification](development/specifications/compiler/index.md)
- [Maintainer workflow](../../docs/guidance-maintenance-workflow.md)
- [Instruction delivery and authority](../../docs/instruction-delivery-and-authority.md)

The compiler records source and output provenance. It does not decide the
instruction priority of the compiled file and does not approve or promote a
candidate.
