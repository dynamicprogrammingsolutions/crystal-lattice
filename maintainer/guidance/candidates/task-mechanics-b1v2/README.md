# Task mechanics B1v2

This candidate extends the frozen
[task-mechanics B1](../task-mechanics-b1/README.md) candidate with the two
calibration corrections selected for the next evaluation round
(September 25, 2026 review of the per-subject reassessment).

Changed section:

- `tasks-v7`

Relative to B1 it adds exactly two rules:

- the decisive production-connection check may not be satisfied by separate
  per-side checks and may not be waived or made conditional on harness
  convenience — if one automated test cannot exercise the full connection,
  the plan must name the check that still traverses the real components
  together;
- a nontrivial execution plan explains the decided design (component
  responsibilities, interfaces or data flow, compatibility and dependency
  states, material decisions, verification strategy) before ordered
  execution steps; ordered steps alone are not a design.

Everything else — the decomposition rules, the conditional technical-layer
rule, status tracking, and every other current section — is inherited from
B1/current unchanged.

Evaluation selects this candidate explicitly and never promotes or writes it
into current guidance.
