# Task mechanics B1

This candidate tests the shortest evidence-backed task decomposition rules
from the current-guidance baseline.

Changed section:

- `tasks-v7`

The candidate:

- defaults to one task;
- permits a child only for an independently acceptable result, owned
  responsibility, compatibility state, or material decision boundary;
- rejects implementation, test, documentation, integration, cleanup, and
  review phases that only complete another delivery;
- permits technical-layer children only when they have independent users,
  ownership, compatibility, or acceptance;
- keeps tests and documentation with the owning outcome;
- requires safe dependencies and one owner for decisive production-connection
  evidence.

Every other current section is inherited. Evaluation selects this candidate
explicitly and never promotes or writes it into current guidance.
