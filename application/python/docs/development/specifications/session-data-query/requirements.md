# Session and message data query requirements

These requirements track the live implementation of the
[session and message data query specification](index.md).

The query contract is implemented, verified, and documented.

| ID | Requirement | Implementation | Verification | Documentation | Evidence |
|---|---|---|---|---|---|
| SDQ-001 | Session and message collection calls with no include or exclude selectors preserve their current routes, envelopes, canonical values, omission rules, ordering, and complete result types. | Implemented | Automated | Documented | Core/application default suites; HTTP legacy fast-path test; frontend SDK complete-after-projected integration; [user guide](../../../session-data-query.md) |
| SDQ-002 | Callers may supply ordered RFC 9535 JSONPath include and exclude selectors; includes union matches with required ancestors, excludes are evaluated against the original document and win, array elements are removed cleanly, and selected canonical indices retain their values. | Implemented | Automated | Documented | `core/python/tests/test_json_projection.py`; Python/CLI/HTTP adapter tests; [JSONPath contract](../../../session-data-query.md#jsonpath-projection) |
| SDQ-003 | Projection remains generic across current and future message roles and metadata discriminators and introduces no role-specific options, closed role registry, named projection presets, or implementation-specific text-search syntax. | Implemented | Automated | Documented | Future-role and metadata-discriminator projection tests; HTTP future-role integration; [generic examples](../../../session-data-query.md#jsonpath-projection) |
| SDQ-004 | Plugin-declared session filters support timezone-aware datetime input and before/after comparisons over built-in or contributed summary fields with equivalent Python and TypeScript normalization. | Implemented | Automated | Documented | Shared `filter-cases.json` Python/TypeScript tests; timestamp plugin tests; mobile/desktop filter tests; [plugin filter guide](../../../../../../plugins/docs/ui-elements.md) |
| SDQ-005 | The local Python runtime lists plugin-filtered session summaries and canonical message ranges with optional include/exclude projection while preserving compact history and explicit full-message lookup. | Implemented | Automated | Documented | `test_local_agent_runtime.py`; source/archive packaged-SDK smokes; [Python guide](../../../session-data-query.md#python) |
| SDQ-006 | `crystal-lattice sessions` uses the active plugin filter schema, supports projection and JSON/text/TSV/CSV formats, and emits exactly one undecorated session ID per line when that is the only selected scalar. | Implemented | Automated | Documented | `test_headless_cli.py`; `test_query_rendering.py`; source/archive/installer smokes; [CLI guide](../../../session-data-query.md#command-line) |
| SDQ-007 | `crystal-lattice messages` retrieves exactly one session range, supports the same projection and formats, emits grep-friendly one-line selected values with session/index/type/path context, and composes safely in a `sessions` shell loop. | Implemented | Automated | Documented | Real CLI subprocess chain and exact renderer tests; source/archive/installer smokes; [shell search](../../../session-data-query.md#command-line) |
