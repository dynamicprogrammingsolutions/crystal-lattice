# Historical Archive

This directory preserves historical conversations, plans, implementation
notes, and ad hoc diagnostics. Its contents are not current product,
architecture, security, release, test, or contributor guidance.

For current information, start with:

- [Repository overview](../README.md)
- [Architecture overview](../README.md#architecture-overview)
- [Contributor guide](../CONTRIBUTING.md)
- [Development documentation](../docs/development/index.md)

Archived material may contain obsolete paths, commands, APIs, assumptions,
performance expectations, or incomplete proposals.

## Contents

- [`conversations/`](conversations/) contains the reviewed historical AGI
  design conversation export.
- [`root-docs/`](root-docs/) contains plans and notes formerly stored at the
  repository root.
- [`plan/`](plan/) and [`plans/`](plans/) preserve the former historical
  planning trees.
- [`root-tests/`](root-tests/) contains unreferenced ad hoc diagnostic scripts
  formerly discoverable as root tests.
- [`server-endpoints-parity.md`](server-endpoints-parity.md) preserves the
  superseded terminal/HTTP endpoint parity phase plan.
- [`documentation-standard-human-review-20260910.md`](documentation-standard-human-review-20260910.md)
  preserves the human-review guide and findings for the superseded seven-page
  documentation standard.
