# Application session-listing requirements

These requirements track the live state relative to the
[application session-listing specification](index.md).

The preserved groups describe behavior that existed before persistent,
deadline-bounded session listing. The new groups describe behavior introduced
by that correction. Functional requirements define results observed by
application users or developers consuming the application API.
Non-functional requirements constrain compatibility, reliability,
performance, encapsulation, concurrency, privacy, and maintainability.

Each evidence cell keeps hand-maintained implementation and documentation
links before `<!-- test-evidence -->`. Test links after that marker are
generated from the structured comments above test functions:

```bash
python scripts/update_session_list_requirement_evidence.py \
  --requirements core/python/docs/development/specifications/session-listing/requirements.md \
  --test core/python/tests/test_application_session_listing.py \
  --test core/python/tests/test_application_session_filters.py \
  --test core/python/tests/test_session_list_cache.py \
  --test application/python/tests/test_session_list_http_contract.py \
  --test application/python/tests/test_agent_terminal_app_server.py
```

Use the same command with `--check` to verify that test links and line numbers
are current.
