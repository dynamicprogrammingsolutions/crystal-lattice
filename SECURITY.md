# Security Policy

## Report Vulnerabilities Privately

Do not open a public GitHub issue for a suspected vulnerability.

Email
[support@dynamicprogrammingsolutions.com](mailto:support@dynamicprogrammingsolutions.com?subject=SECURITY%3A%20Crystal%20Lattice)
with a subject beginning with `SECURITY:`. If GitHub's private
"Report a vulnerability" option is visible for this repository, that private
channel may also be used.

Include, where possible:

- the affected package, application, service, version, or commit;
- the security impact and the conditions required to reproduce it;
- concise reproduction steps or a proof of concept;
- affected platforms and configurations;
- sanitized logs, screenshots, or suggested remediation.

Do not send live credentials, private keys, access tokens, private
conversations, or unnecessary personal data. If a credential may have been
exposed, revoke or rotate it first and report only the minimum identifying
information needed to investigate.

Allow time for the report to be reviewed before disclosing details publicly.
The project does not currently publish a guaranteed acknowledgement,
remediation, disclosure, or embargo timeline.

## Supported Versions

Crystal Lattice is in early development and does not have a fixed security
support or backport window. Security work is prioritized for the current
development line and latest published release as practical. Older releases may
not receive a patch.

## Scope And Expectations

Reports concerning Crystal Lattice source code, bundled first-party plugins,
official mobile or desktop applications, repository automation, and project
deployment tooling are in scope.

Third-party AI providers, GitHub, Apple, Google, cloud providers, and
independently operated Crystal Lattice deployments are generally controlled by
their respective providers or operators. A report is still useful when a
Crystal Lattice integration creates or worsens the exposure.

The project does not currently operate a public bug-bounty program and makes no
promise of payment or other reward.
