# Cloud Runtime Preinstalled Plugin E2E Assertions
Add local cloud-orchestrator E2E coverage proving default plugins are installed at Docker image build time and are not reinstalled into the runtime plugin cache when a cloud instance starts.

- [x] Keep the assertion realistic: use the existing public local app -> orchestrator -> cloud runtime flow, and inspect only local Docker/image/cache artifacts already available to the harness.

## Implementation Notes

The local TypeScript harness already builds the runtime image in
`packages/frontend-sdk/src/integration/harness.ts`:

```ts
docker build -t cloud-agent-runtime:latest -f cloud-orchestrator/runtime/python/Dockerfile .
```

For local mode, add an image-level helper in
`packages/frontend-sdk/src/integration/__tests__/cloud-orchestrator.e2e.integration.test.ts`
that runs a short Python probe inside the built image, for example:

```ts
function expectRuntimeImagePreinstalledPlugins(): void {
  if (CLOUD_ORCHESTRATOR_E2E_MODE && CLOUD_ORCHESTRATOR_E2E_MODE !== 'local') {
    return;
  }

  const script = `
import importlib.util
import json
from pathlib import Path

root = Path("/opt/ai-agent-platform/cloud-runtime-plugin-bundle")
manifest = json.loads((root / "manifest.json").read_text())

for name in ["cloud-agent-app", "codex-tools", "session-title-app"]:
    assert name in manifest["preinstalled_plugins"], name
    descriptor = json.loads((root / "bundled_plugins" / name / "agent_plugin.json").read_text())
    assert descriptor.get("preinstalled") is True, name

for module in ["cloud_agent_app", "codex_tools"]:
    assert importlib.util.find_spec(module) is not None, module
`;
  execFileSync(
    'docker',
    ['run', '--rm', 'cloud-agent-runtime:latest', 'python3', '-c', script],
    { stdio: 'pipe' },
  );
}
```

Then add a cache-level helper for local mode. The Docker runner mounts:

```text
<orchestrator.dataDir>/runtime-cache -> /cloud-agent/cache
```

The cloud transfer code rewrites runtime config to:

```json
"plugin_cache_dir": "/cloud-agent/cache/plugin_cache/plugins"
```

So the test can inspect:

```text
${orchestrator.dataDir}/runtime-cache/plugin_cache/plugins
```

Suggested helper:

```ts
function expectCloudRuntimePluginCacheEmpty(
  orchestrator: StartedCloudOrchestrator,
): void {
  if (CLOUD_ORCHESTRATOR_E2E_MODE && CLOUD_ORCHESTRATOR_E2E_MODE !== 'local') {
    return;
  }

  const pluginCache = path.join(
    orchestrator.dataDir,
    'runtime-cache',
    'plugin_cache',
    'plugins',
  );
  if (!fs.existsSync(pluginCache)) {
    return;
  }

  const entries = fs
    .readdirSync(pluginCache, { withFileTypes: true })
    .filter((entry) => entry.isDirectory())
    .map((entry) => entry.name)
    .sort();

  expect(entries).toEqual([]);
}
```

Call the image assertion after `startCloudOrchestratorForE2E()` in the first
local orchestrator test. Call the cache assertion after
`waitForCloudInstanceRunning(...)` and after a simple cloud runtime request
such as `cloudBackend.listAgents()` confirms the `AgentApplication` was
initialized.
