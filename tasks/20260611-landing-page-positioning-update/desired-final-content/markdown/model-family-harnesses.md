Different model families are optimized around different coding harnesses. GPT-5.5 works well with Codex-style tools. Claude Opus works well with Claude Code-style behavior. Gemini, Qwen, Kimi, and Grok each have their own expectations.

Crystal Lattice uses plugins to provide simplified tool sets, system messages, request behavior, and UI controls that feel familiar to those models.

The goal is simple: the model should not have to fight the harness. If a model family works best with a particular patch format, tool schema, system message style, or provider feature, that behavior can live in a plugin.
