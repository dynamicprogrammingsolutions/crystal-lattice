Agent work is more than a transcript. A session can carry titles, pinned state, summaries, snapshots, attachments, and custom actions supplied by plugins.

That makes sessions durable workspaces rather than disposable chat logs. You can return to a previous thread, fork from a useful point, preserve generated assets, or add the session actions your own workflow needs.

These operations are plugin-driven, so the workbench can change with your workflow instead of being limited to whatever the main app hardcoded.
