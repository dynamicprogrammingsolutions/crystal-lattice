# General-Purpose Harnesses

Add built-in general-purpose harnesses for ordinary users, alongside the
development-focused default agents.

## Requirements checklist

- [ ] Define general-purpose agent profiles for common use outside software development.
- [ ] Decide which model families should get general-purpose defaults first.
- [ ] Keep development-focused harnesses available and clearly named.
- [ ] Ensure general-purpose harnesses use appropriate system messages, tools, and UI controls.
- [ ] Add tests or config validation coverage for the new default agents.
- [ ] Update docs and landing page copy if these harnesses are added.

Parent Task: `tasks/20260611-landing-page-positioning-update/000-main.md`

## Context

The current default config is strongly development-oriented, with coding
harnesses and tools. The landing page should avoid implying that Crystal
Lattice is only for developers. General-purpose built-in harnesses would make
the broader "power user" positioning more credible.
