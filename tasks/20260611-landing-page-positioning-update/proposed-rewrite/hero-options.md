# Hero Options

These are alternate hero directions for the landing page rewrite. The main
draft currently uses the one-size-fits-all audience angle. Notes are included
so future reviewers can choose based on the audience they want to emphasize.

## Option A: One-size-fits-all Agents

Best for power users who have already felt the limits of generic agent tools.

```text
For people who outgrow one-size-fits-all agents.

Crystal Lattice is a model-native agent platform: the harness changes around
the model, including its system message, tool schema, request behavior,
provider-native state, and UI controls. Built-in plugins provide Codex, Claude,
Gemini, Qwen, Kimi, and Grok-style defaults, and your config can replace them.
```

## Option B: Inspectable Harness

Best for users who want to understand what the agent is actually running with.

```text
Know the harness your agent is running in.

Crystal Lattice makes the agent harness visible and replaceable. Built-in
plugins provide model-native defaults for major model families, while your
config decides which providers, tools, system messages, native features, and UI
actions are active.
```

## Option C: Ownership

Best for users who identify with ownership and control, without listing product
features as the audience definition.

```text
The agent is yours. The harness should be too.

Crystal Lattice gives you a visible, replaceable harness for serious agent
work. Start with built-in model-family defaults, run the agent on your computer,
and keep control over how the model is prompted, tooled, configured, and shown
in the UI.
```

## Option D: Direct Model-Native Differentiation

Best when the page wants to lead with the strongest technical differentiator.

```text
Stop forcing every model through the same harness.

Crystal Lattice ships built-in model-family plugins for Codex, Claude, Gemini,
Qwen, Kimi, and Grok. Each harness can define the system message, tool schema,
request behavior, provider-native state, and UI controls that model family
works best with.
```

## Option E: Anywhere Workflow

Best when the primary goal is to get users excited about phone and app UIs.

```text
Your local agent, reachable from anywhere.

Run Crystal Lattice on your computer and control the same sessions from
desktop, mobile, terminal, Python, or your own UI. The same built-in
model-family plugins, provider settings, and session actions travel with the
workspace.
```

## Option F: Know What's Happening

Best for users who are skeptical of opaque agent products.

```text
For people who want to know what their agent is doing.

Crystal Lattice turns the harness into something you can inspect and replace:
which model-family instructions are active, which tools are available, which
provider-native features are enabled, and which plugin actions can affect the
session.
```
