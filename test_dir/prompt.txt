Task
- Compute an index p in [0..9] BEFORE calling any tools.
- After computing p, call a tool to load a JSON bank from disk (see file paths mapping below).
- From the returned JSON, output ONLY the label (string) of the single item whose id == p. Use the file content purely as a lookup keyed by p.
- Output exactly the label string and nothing else.

Algorithm (deterministic):
1) From the SEED text, extract only alphabetic characters A–Z (ignore everything else), uppercase the result; call it A. Let L = len(A).
2) Map letters A..Z to values 1..26.
3) Compute Salpha = sum
over i=1..|A| of v(A[i]) * w(i), where i is 1-based and w(i) =
((i-1) mod 3) + 1 (weights repeat 1,2,3 starting at i=1).
4) Extract all decimal digits from the SEED; let Sdigits be their sum.
5) Split the SEED into alphabetic words (maximal [A-Za-z]+). Let W be the list of words. Let Wc be the count of words whose first letter’s value is even (i.e., first letter in {B,D,F,H,J,L,N,P,R,T,V,X,Z}).
6) Compute p = (Salpha + 7*Sdigits + 11*Wc + L) mod 10.
7) Determine which bank to use (do not change p):
   7a) Split SEED into alphabetic words. For each word, count its letters; let Slen be the sum of these per-word lengths.
   7b) Compute f = (Slen + L + p) mod 3. This selects the bank index f ∈ {0,1,2}.

SEED (use exactly the text between SEED: and the end of this block):
SEED:
Fennel 983; Olive 193; Graphite 668.

Constraints
- Do not reveal p in your tool preamble
- After the tool returns, output only the single matching label (id == p), with no additional text.

File paths mapping for the tool call (based on f computed in the Algorithm):
- f=0 -> path "bank0.json"
- f=1 -> path "bank1.json"
- f=2 -> path "bank2.json"

Now, call a tool to read the selected file from disk using one of the paths above.
