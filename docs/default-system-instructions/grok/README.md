# Grok Default System Instructions

This directory is optimized for humans reconstructing Grok-flavored system instructions.

Suggested workflow:

1. Start from `template.md`.
2. Replace each section placeholder with the corresponding section file.
3. Replace the smaller placeholders inside those files using `dynamic-elements.md`.
4. Use `compiled.md` as a worked example.
5. Use `agent-notes.md` only for deeper source tracing or future automation work.
