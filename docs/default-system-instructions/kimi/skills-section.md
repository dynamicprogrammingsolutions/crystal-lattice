# Skills

Skills are reusable, composable capabilities that enhance your abilities. Each skill is a self-contained directory with a `SKILL.md` file that contains instructions, examples, and reference material.

## Available skills

${KIMI_SKILLS}

## How to use skills

Identify the skills that are likely to be useful for the tasks you are currently working on, then read the `SKILL.md` file for detailed instructions, guidelines, scripts, and more.

Only read skill details when needed to conserve the context window.
