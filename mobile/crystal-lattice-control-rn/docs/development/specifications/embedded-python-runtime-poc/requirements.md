# Embedded Python runtime proof-of-concept requirements

These requirements track the live implementation of the
[embedded Python runtime proof of concept](index.md).

| ID | Requirement | Implementation | Verification | Documentation | Evidence |
| --- | --- | --- | --- | --- | --- |
| IPR-001 | A release-like iOS application bundle contains and starts the fixed CPython/Crystal Lattice closure without a desktop process, loopback application server, runtime download, or dynamic plugin installation. | Implemented | Automated | Documented | Pinned Python Apple Support preparation; signed simulator and physical-device Release builds; focused Detox imports real `agent_core`/`agent_app` and constructs `AgentApplication`; embedded-runtime development guide |
| IPR-002 | The mobile application exposes the embedded runtime through a production `inProcess` `AgentBackend` that supports the fixed agent, sessions, messages, request events, cancellation, and the proof-of-concept configuration action. | Implemented | Automated | Documented | Native JSON transport plus `RestAgentBackend(kind: "inProcess")`; host integration; focused SDK tests; diagnostics covers agents, sessions, events, and messages; production setup Detox covers configuration and reconnect |
| IPR-003 | One fixed agent uses the reference OpenAI-compatible provider through an API-key-protected proxy backed by Ollama and completes a real multi-round request. | Implemented | Automated | Documented | Host integration and release-simulator Detox complete two explicit user requests using both `Read` and `Write` through authenticated local Ollama `qwen3.5:0.8b`, with persisted tool messages and verified output content |
| IPR-004 | The proxy rejects missing or incorrect bearer credentials, accepts the configured key, preserves required OpenAI-compatible streaming/non-streaming behavior, and does not log the credential. | Implemented | Automated | Documented | Six `tools/openai-proxy` tests; real API-key-protected Ollama `qwen3:0.6b` request; proxy README |
| IPR-005 | The app accepts a masked proof-of-concept API key, supplies it through an app-owned configuration overlay, and reconstructs the complete `AgentApplication` without exposing the key in prompts, events, tools, logs, or committed configuration. | Implemented | Automated | Documented | Production setup Detox rejects a wrong key, accepts the correct masked input, persists owner configuration across process relaunch, and reconnects without re-entry; saved connection, prompts, events, tools, proxy logs, and committed config contain no key |
| IPR-006 | General text `Read` and `Write` tools operate only on logical paths under one canonical app-owned workspace and reject absolute paths, traversal, and symlink escape. | Implemented | Automated | Documented | Focused unit tests cover nested text round trip and reject absolute paths, traversal, and symlink escape; real simulator tool loop verifies the app-owned output |
| IPR-007 | Session and workspace state survive navigation, runtime reconstruction, and process relaunch for the proof-of-concept flow. | Implemented | Automated | Documented | Setup Detox reconnects the saved production connection after process relaunch; persistence Detox loads the same session ID, tool messages, and `output.txt` in a fresh process without replaying the chat request |
| IPR-008 | An active request receives bounded iOS background handling, durable lifecycle timestamps/state, and visible completion or recoverable interruption without automatic duplicate provider execution. | Implemented | Automated + inspected | Documented | Native host owns an iOS background task and persists running/background/completed/failed/cancelled/expired/interrupted state; delayed release-simulator Detox backgrounds for five seconds and verifies ordered background/completion timestamps plus final output; expiration and relaunch-interruption paths are inspected |
| IPR-009 | Focused automated simulator coverage exercises production screens and adapters and is sufficient acceptance evidence for the proof of concept. | Implemented | Automated | Documented | Production setup, credential-free smoke, real tool-loop persistence, and delayed background continuation pass on an iPhone 17 Pro simulator; simulator sufficiency confirmed by user direction on 2026-09-10 |
| IPR-010 | The proof of concept remains limited to one agent/provider, workspace `Read`/`Write`, basic credentials, and lifecycle evidence; Tavily search, restricted Python, ChatGPT authorization, local models, and broader production hardening are not falsely presented as delivered. | Implemented | Inspected | Documented | Specification exclusions, package README, and embedded-runtime development guide state the delivered scope and current limits |
